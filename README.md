# College FAQ Chatbot

An AI-powered College FAQ Chatbot developed using Python.

## Technologies
- Python
- NLTK
- Scikit-learn
- Streamlit
- TF-IDF
- Cosine Similarity

## Features
- Answers college-related questions.
- NLP text preprocessing.
- FAQ similarity matching.
- Interactive chatbot interface.
- Suggested questions.
- Clear chat option.

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the chatbot:

streamlit run app.py
